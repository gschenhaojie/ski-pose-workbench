# 滑雪镜头台

在浏览器里给 3D 双板滑雪人物摆姿势、选机位，导出图生视频所需的参考图和提示词。应用在自己的电脑上运行。

## 让 Codex 安装

把下面这段发给电脑上的 Codex。

> 请从 https://github.com/gschenhaojie/ski-pose-workbench 下载滑雪镜头台到我的电脑，检查 Node.js。缺少运行环境时帮我安装 Node.js LTS。然后在项目目录运行 `npm start`，确认浏览器打开「滑雪镜头台」，并告诉我下次双击哪个文件启动。

## 自己启动

电脑需要 Node.js 22.12+，也支持 Node.js 20.19+ 的 20.x 版本。第一次启动会联网安装项目依赖。

- **Mac** 双击 `Start-Mac.command`。如果提示没有执行权限，让 Codex 在项目目录运行 `chmod +x Start-Mac.command`。
- **Windows** 双击 `Start-Windows.cmd`。
- **终端** 在项目目录运行 `npm start`。

启动后会自动打开浏览器。使用期间请保留启动窗口。默认地址是 `http://127.0.0.1:5187/`，端口占用时以启动窗口显示的地址为准。使用支持 WebGL 2 的浏览器。

## 摆姿势和导出

1. 从基础、转弯、点杖和跳跃共 16 个预设里选一个。拖动圆点调整髋部、双手和双脚，或用滑块调上身。
2. 点击「锁住姿势」，再试六个快捷机位，或拖动视窗空白处绕拍。
3. 下载当前姿势的 PNG，并复制提示词或下载 TXT。「人物参考」可以查看和下载正面、侧面、背面三张原图。
4. 将人物原图、当前姿势 PNG 和提示词一起交给支持多图参考的生图工具。三视图决定外观，PNG 确定本次姿势和机位。

工作台提供静态构图参考。可编辑白模是参照三视图制作的关节模型。刷新后回到默认姿势和机位。

## 开发和许可

`npm ci` 安装依赖，`npm run dev` 启动开发预览，`npm run build` 执行类型检查与构建。
